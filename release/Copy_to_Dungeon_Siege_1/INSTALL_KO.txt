Ultima V: Lazarus 한국어 패치 B104 - 붙여넣기 설치
======================================================

[필수 조건]

1. Dungeon Siege 1을 설치합니다.
2. Ultima V: Lazarus 1.20을 설치합니다.

한국어 Language.dll, Language.dsres와 Lazarus 글꼴 설정이 패키지에 포함되어 있으므로
별도의 Dungeon Siege 1 한글 패치를 먼저 설치할 필요가 없습니다.

포함된 Language.dll은 원본 한국어 리소스 429개의 내용을 그대로 보존하고
PE 리소스 컨테이너만 다시 패킹한 Steam 호환본입니다. 구형 원본 DLL에서
게임 종료 시 발생하던 SmartHeap MEM_BAD_POINTER 경고를 방지합니다.

[설치]

1. 게임 폴더의 다음 파일을 반드시 백업합니다.
   Resources\lazarus_logic.dsres
   Resources\britannia_logic.dsres
   Resources\Language.dsres (기존 파일이 있을 때)
   Language.dll (기존 파일이 있을 때)

2. Copy_to_Dungeon_Siege_1 폴더 안의 내용 전체를 Dungeon Siege 1
   게임 폴더에 그대로 붙여넣고 파일 교체에 동의합니다.

   기본 경로:
   C:\Games\Steam\steamapps\common\Dungeon Siege 1

3. Create_Ultima_V_Lazarus_Shortcut.cmd를 더블클릭합니다.
   바탕화면에 Ultima V - Lazarus v1.20 바로가기가 생성됩니다.

[제거]

백업한 lazarus_logic.dsres, britannia_logic.dsres, Language.dsres,
Language.dll을 원래 위치로 복원하고
Resources\zzz_U5K_Text_OnDemand.dsres를 삭제합니다.

[알려진 제한]

- PSD 이미지에 그려진 텍스트 81개는 번역 대상에서 제외했습니다.
- B104 런타임 잔존 영문 정적 QA를 반영했습니다. 실제 게임 실행 호환성은 DungeonSiege.exe에서 최종 확인이 필요합니다.

서적의 페이지 이동 및 세로 스크롤 동작은 Ultima V: Lazarus 원본과 동일합니다.
